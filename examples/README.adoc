= examples Pillar

`heron.json` is a complete, valid `heron` configuration: three feed sources,
one monitor with change detection, robots.txt checking and certificate-expiry
warning, and the web UI enabled on `127.0.0.1:8484`. `just test-smoke`
validates it with `heron check-config`; `docs/usage.adoc` documents every key.
