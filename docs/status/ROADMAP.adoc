= heron-polyfeed-reader Roadmap

The STATE journal of heron-polyfeed-reader: milestones, blockers and next
actions. Phase and maturity are not recorded here; they live in the repo deed,
`heron-polyfeed-reader_chora.deed`, in the `(status …)` and `(maturity …)`
clauses (`just state-phase` prints both).

This file absorbs the handoff note (`HANDOFF.md`, written 2026-10-19) that
travelled with the M0–M6 import on 2026-10-27. That note is retired here; its
build and test instructions moved to `README.adoc` and `CONTRIBUTING.adoc`.

Ground truth at import (2026-10-27, Zig 0.17.0 exactly, x86_64 Linux host):

== Blockers

. *Clade is UNASSIGNED* in the deed. Choosing it is the owner's act (the
  template says so); `just validate-rsr` fails until it is chosen. The
  ecosystem `:position-type` is UNASSIGNED for the same reason.
. *Signing.* The M7 integration commits were prepared in a session with no
  signing key. They must be committed with `id_ed25519_signing` locally
  before push; the eleven imported milestone commits keep their own
  signatures.
. *Idris2 ABI seam.* `just test` and `just build` run every detected
  language. The template's `src/interface/abi.ipkg` (Idris2) is detected
  alongside `build.zig`; without `idris2` on PATH the Zig steps pass but the
  recipe exits non-zero. Decide whether the seam stays (then provision
  `idris2` via pack, as the template expects) or whether this project opts
  out (then `validate-rsr`, which hard-requires `src/interface/{abi,ffi,generated}`,
  needs a ruling).
. *mise.lock was edited by hand* for the Zig 0.17.0 pin (no `mise` in the
  import session). Checksums are the official ones from
  `ziglang.org/download/index.json`; re-lock with `just toolchain-refresh` to
  confirm.

  review-app finding and CI anomaly, merge.

* Re-count the container `test` stage after the rename (host run was 85/85;
  `zig-ci.yml` now builds that stage on every push).

== Known gaps / untested

* Never run against live public sites; every HTTP test uses a local fixture
  server.
* Certificate probe verified only against a self-signed certificate.
* Web UI exercised via raw HTTP, not a browser; no search pagination.
* x86_64 Linux only; no soak test; RSS measured once.
* The adapter interface is meant to take NNTP, Gopher, Gemini, ActivityPub
  and AT Protocol without core changes; unproven until M8.

== Design decisions made without owner input (revisit freely)

* JSON config, no YAML; web UI off unless configured; default bind
  `127.0.0.1:8484`; a non-loopback bind needs `web.allow_non_loopback`.
* Web UI: Host-header allowlist (DNS rebinding), Origin check on POST, CSP,
  no JavaScript, http(s)-only links, its own SQLite connection.
* Monitor alerts are stored as items of kind `alert`; the first success is a
  silent baseline; DOWN after two failures; change alerts rate-limited to
  one per hour.
* WebSub deliberately not implemented.
* Binary `heron`, environment `HERON_CONFIG` / `HERON_DATA`, lock file
  `heron.lock`.
