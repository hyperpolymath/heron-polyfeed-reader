= Proof Status — heron-polyfeed-reader

Status words are the closed vocabulary of the estate PROOF-POLICY §5:
PROVEN, PROVEN-WITH-AXIOMS, TESTED (with bounds), ASSUMED, OPEN. Every row
below was run, not read; the date and toolchain are on the row.

== Summary

heron owns *no proof of its own yet*. Everything under
`verification/proofs/` is the RSR template's worked examples about example
types (a bounded natural number, a toy expression language). They are kept
compiling by `just proof-check-all`, and they are correct, but they prove
nothing about heron. The mathesis estate census agrees: it records heron
with zero own proofs.

heron's real formal boundary is its SQLite C API: 22 hand-written `extern`
declarations (`src/sqlite.zig`, `src/store.zig`). Its obligations are
SEAM-1 to SEAM-4 in `PROOF-NEEDS.adoc`.

== heron's own obligations

[cols="1,4,1,4", options="header"]
|===
| ID | Obligation | Status | Evidence

| SEAM-1
| The 22 SQLite declarations agree with `vendor/sqlite/sqlite3.h` (SQLite
  3.50.4): arity, parameter and return types, nullability and integer width;
  and the 9 constants heron uses (`SQLITE_OK`, `ROW`, `DONE`, the four
  `OPEN_*` flags, `SQLITE_TRANSIENT`, `SQLITE_NULL`) equal the header's.
| TESTED
| 2026-11-09, one-off: each declaration compared with the output of
  `zig translate-c vendor/sqlite/sqlite3.h` (Zig 0.17.0). Bounds: this SQLite
  version, x86_64-linux. Nothing re-checks it; SEAM-4 is the planned route.

| SEAM-2
| SQLite behaves as its documented C API.
| ASSUMED
| Third-party code (PROOF-POLICY §1.1).

| SEAM-3
| The `setpriority` declaration in `src/daemon.zig` matches the C library.
| OPEN
| Not checked.

| SEAM-4
| One source for the SQLite boundary: an Idris2 description generates the
  Zig declarations, run through idris2x.
| OPEN
| Owner decision 2026-11-09. A scratch experiment comes first.
|===

== Verification Commands

[source,bash]
----
# Every prover; FATAL if a toolchain is missing
just proof-check-all

# One prover
just proof-check-idris2
just proof-check-lean4
just proof-check-agda
just proof-check-coq
----

`just proof-check-all` is not run by any GitHub workflow yet: wiring it into
CI waits on idris2x (see `docs/status/ROADMAP.adoc`).
