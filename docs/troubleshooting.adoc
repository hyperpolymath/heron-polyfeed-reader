= Troubleshooting — heron-polyfeed-reader
:revdate: 2026-10-27

This file is a *living FAQ* — known failure modes and recovery paths.
Add a new entry every time you debug something that took more than 15
minutes.

== Known failure modes

=== `zig build` fails with errors inside `std` (`std.Io`, `std.http`, TLS)

**Symptom**: compile errors in standard-library code, or `@cImport` reported
as unknown.

**Cause**: wrong Zig. The project needs 0.17.0 exactly; 0.15/0.16 changed
these APIs and `@cImport` no longer exists in 0.17.

**Fix**:
[source,bash]
----
zig version            # must print 0.17.0
mise install           # installs the pinned version from mise.toml
----

**Avoidance**: let mise manage the toolchain; the Containerfile pins the same
version by SHA-256.

---

=== `zig fmt --check` lists files after a Zig upgrade

**Symptom**: `just lint` fails naming source files that were clean before.

**Cause**: a new Zig renames builtins or re-wraps literals (0.17 renamed
`@intFromEnum` to `@backingInt`); the formatter applies the migration.

**Fix**: `zig fmt build.zig src`, read the diff, commit it on its own.

---

=== The web UI is unreachable from the host when running in a container

**Symptom**: `curl http://127.0.0.1:8484/` on the host gets connection refused.

**Cause**: the daemon binds `127.0.0.1` *inside* the container.

**Fix**: in the config, `"web": {"bind": "0.0.0.0", "allow_non_loopback": true}`,
and publish the port loopback-only on the host: `-p 127.0.0.1:8484:8484`.

**Avoidance**: never publish the UI on a non-loopback host address; it has no
authentication.

---

=== `daemon` exits immediately: lock file held

**Symptom**: the daemon refuses to start and names `heron.lock`.

**Cause**: another daemon is running on the same data directory, or one died
without releasing the lock.

**Fix**: stop the other instance; if none is running, remove `heron.lock`
from the data directory and start again.

---

=== Items missing after an unclean shutdown

**Symptom**: `list` shows fewer items than the log holds.

**Cause**: the index fell behind the log.

**Fix**: `heron rebuild` rebuilds the SQLite index and FTS5 tables from the
NDJSON log. The daemon also replays records past `meta.indexed_offset` on
start, so this is rarely needed by hand.

---

=== `search` returns nothing for a short query

**Symptom**: `heron search ab` finds nothing although items contain "ab".

**Cause**: the trigram index needs at least three characters.

**Fix**: use three or more characters.

== Diagnostic toolkit

[source,bash]
----
heron check-config            # validate the config file
heron sources                 # per-source status: last check, failures, next poll
heron monitors                # per-monitor status: up/down, HTTP status, certificate expiry
zig build test --summary all  # the unit suite
just doctor                   # estate self-checks
----

== When to escalate

. File an issue with: version, OS, exact command, full error output,
  and the symptom in plain English.
. Link the relevant ADR(s) and any related issues.
. For *security*-relevant findings, see
  link:../.github/SECURITY.md[SECURITY.md] — do **not** file public issues.
